# にほんごジャーニー | 日语学习仓库

个人日语学习系统：**零基础 → 出国旅游自如 + 无字幕看日剧**。

- 每日投入：约 1 小时（手机为主）
- 学习方式：免费网络资源 + 纸面手写 + AI 教练（Trae 对话）
- 打卡方式：GitHub Issue（手机 1 分钟完成）

## 三步上手（手机版）

1. **看课**：打开 [路线图](docs/roadmap.md) 里 AI 指定的本周资源链接
2. **打卡**：在仓库 Issues 页面点 `New issue` → 选「每日打卡」模板 → 填四行 → 提交并关闭
3. **周复盘**：每周日把本周打卡发给 AI（Trae），生成周报

## 四阶段路线

| 阶段 | 周期 | 目标 |
|---|---|---|
| 1 地基 | 第 1-6 周 | 五十音读写无碍，能自我介绍 |
| 2 旅游实战 | 第 7-16 周 | 应对日本自由行六大场景 |
| 3 听力浸泡 | 第 17-40 周 | 看懂日剧 60-70%，日常对话听懂 |
| 4 流利输出 | 第 41-52 周 | 无字幕看日常番剧，口语应对自如 |

详见 [docs/roadmap.md](docs/roadmap.md)。

## AI 教练的四个角色

用 Trae 对话扮演你的日语教练：

1. **任务教练**：每天开始前说「给我今天的日语任务」→ AI 读你的进度并给出当日清单
2. **即时老师**：把造的句子/疑问贴给 AI → 批改讲解
3. **对话陪练**：阶段 2 起说「来练点餐场景」→ AI 角色扮演
4. **周复盘官**：周日说「复盘本周日语」→ AI 汇总打卡出周报
