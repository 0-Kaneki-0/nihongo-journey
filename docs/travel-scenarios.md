# 旅游情景句库

> 阶段 2 专用。格式：日文 / 罗马音 / 中文。每个场景先背核心 8 句，再让 AI 陪练扩展。

|---|---|---|
| すみません、メニューをください。 | sumimasen, menyuu o kudasai | 不好意思，请给我菜单 |
| これをおねがいします。 | kore o onegai shimasu | 我要这个 |
| おすすめはなんですか。 | osusume wa nan desu ka | 有什么推荐？ |
| これはなんですか。 | kore wa nan desu ka | 这是什么？ |
| 水をください。 | mizu o kudasai | 请给我水 |
| おいしいです！ | oishii desu! | 好吃！ |
| おかいけいをおねがいします。 | okaikei o onegai shimasu | 请结账 |
| いっしょにたべますか。 | issho ni tabemasu ka | 要一起吃吗？ |

## 练习规则

1. 每场景先用「看日文想中文 → 看中文想日文」过 3 遍
2. 手写每句 1 遍（输出环节的 3 句从当前场景选）
3. 对 AI 说「来练点餐场景」角色扮演，AI 扮演店员/路人
