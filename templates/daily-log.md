# 每日打卡模板

> GitHub Issue 已内置此模板；此文件供参考。填写四行即可，1 分钟内完成。

```
## 今日学了
（写今天看了哪一课/哪段视频，新词几个）

## 手写词数
（今天纸面写了几个词：如 10 词 + 3 句）

## 浸泡内容
（看了/听了什么，几分钟）

## 造句
（当天 3 个句子的日文+中文；想被批改就发给 AI）
```

## 示例

```
## 今日学了
五十音 な行、ま行；JapanesePod101 第 2 课「自我介绍」

## 手写词数
10 词 + 3 句

## 浸泡内容
Comprehensible Japanese #12，15 分钟

## 造句
わたしはがくせいです。（我是学生。）
すしがすきです。（喜欢寿司。）
よろしくおねがいします。（请多关照。）
```

**核对清单：今日 60 分钟 = 复习 10 + 新知 30 + 浸泡 15 + 手写输出 5**
